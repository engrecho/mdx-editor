## 一、三分钟上手

### 第 1 步：装好应用

**Windows**：双击 `轻墨 Setup 1.1.0.exe` → 一路下一步 → 完成。
  
如果提示「未知发布者」，点「更多信息」→「仍要运行」。

**macOS**：解压 zip → 把 `轻墨.app` 拖进「应用程序」→ **右键点击它** → 选「打开」。

### 第 2 步：新建文档

按 `Ctrl+N`，或者点左上角第一个图标（一张纸加号）。

### 第 3 步：开始写

左边敲字，右边自动出效果。默认有一段欢迎文档，照着改就行。

### 第 4 步：保存

按 `Ctrl+S`，选个位置，起个名字，比如 `我的文章.md`。

**完事了。** 剩下的都是可选的锦上添花。

## 二、界面详解

```
┌────────────────────────────────────────────────────────────┐
│ 轻墨   周报.md          ✎ ⊞ ⌗ ...  ▦ ❝   ◫ ▨ ◐           │
├──────────────────────────┬─────────────────────────────────┤
│                          ┃                                 │
│  # 周报                   ┃   周报                          │
│                          ┃   ═════                         │
│  这周做了三件事：         ┃                                 │
│                          ┃   这周做了三件事：               │
│  - 重构了登录模块         ┃   • 重构了登录模块               │
│  - 修了 12 个 bug         ┃   • 修了 12 个 bug               │
│  - 写了周报              ┃   • 写了周报                    │
│                          ┃                                 │
│              ← 拖这条竖线 → ┃                                │
├──────────────────────────┴─────────────────────────────────┤
│ /Users/you/Documents/周报.md · 行 3, 列 2   ●未保存  128字  6行 │
└────────────────────────────────────────────────────────────┘
```

### 标题栏（左→右）

| 元素                    | 作用                                                 |
| --------------------- | -------------------------------------------------- |
| **轻墨**                | 应用标识                                               |
| **文档名**               | 当前打开的文件名                                           |
| 📄💾⬇️                | 新建 / 保存 / 导出 HTML                                  |
| H1 H2 H3              | 插入标题，再按一次变回正文                                      |
| **B** *S* `</>`       | 加粗 / 斜体 / 删除线 / 行内代码                               |
| ▦ ❝ ❮❯ • 1. ☑ — 🔗 🖼 | 表格 / 引用 / 代码块 / 有序列表 / 无序列表 / 任务列表 / 分隔线 / 链接 / 图片 |
| ◫ ▨ ◐                 | 视图切换（编辑 / 分栏 / 预览）、深色模式                            |

> 悬停任意图标会显示快捷键提示。

### 中间的竖线

按住上下拖不动，**左右**拖可以调整两侧宽度。
  
范围限制在 20% ~ 80%，防止某一边被挤没。

### 状态栏

| 显示                 | 含义       |
| ------------------ | -------- |
| `文件路径 · 行 12, 列 4` | 光标在哪     |
| `● 未保存`（橙色）        | 有改动还没保存  |
| `已保存`（绿色）          | 已存盘      |
| `1,284 字`          | 不含空格的字符数 |
| `96 行`             | 总行数      |

## 三、快捷键全表

**macOS 用户**：把下表的 `Ctrl` 换成 `⌘ Command`。
  
`Ctrl+Shift+X` 这种组合，对应 `⌘+Shift+X`。

| 操作      | 快捷键            | 在哪         |
| ------- | -------------- | ---------- |
| 新建      | `Ctrl+N`       | 文件菜单 / 工具栏 |
| 打开      | `Ctrl+O`       | 文件菜单 / 工具栏 |
| 保存      | `Ctrl+S`       | 文件菜单 / 工具栏 |
| 另存为     | `Ctrl+Shift+S` | 文件菜单       |
| 导出 HTML | `Ctrl+Shift+E` | 文件菜单 / 工具栏 |
| 打开最近文件  | 鼠标点            | 文件 → 最近打开  |

### 编辑

| 操作   | 快捷键            |
| ---- | -------------- |
| 撤销   | `Ctrl+Z`       |
| 重做   | `Ctrl+Shift+Z` |
| 查找替换 | `Ctrl+F`       |
| 缩进   | `Tab`          |
| 反缩进  | `Shift+Tab`    |

### 格式（都是「可切换」的）

| 操作   | 快捷键              | 按一次        | 再按一次  |
| ---- | ---------------- | ---------- | ----- |
| 加粗   | `Ctrl+B`         | `**文字**`   | 恢复原样  |
| 斜体   | `Ctrl+I`         | `*文字*`     | 恢复原样  |
| 删除线  | `Ctrl+Shift+X`   | `~~文字~~`   | 恢复原样  |

### 插入

| 操作   | 快捷键            | 有选中时       | 无选中时               |
| ---- | -------------- | ---------- | ------------------ |
| 表格   | `Ctrl+T`       | 首行作表头自动建表  | 插 3×3 空表           |
| 引用   | `Ctrl+Shift+Q` | 每行加 `>`    | 插入空引用              |

| 分隔线  | `Ctrl+Shift+M` | ——         | 插入 `---`           |
| 链接   | `Ctrl+Shift+L` | 选中文字作链接文字  | `[链接文字](https://)` |
| 图片   | `Ctrl+Shift+I` | ——         | `![描述](https://)`  |

### 视图

| 操作   | 快捷键      |
| ---- | -------- |

## 四、Markdown 语法速查

轻墨的预览区支持标准 Markdown + GitHub 扩展语法（GFM）。

| 想要的效果   | 怎么写                        |
| ------- | -------------------------- |
| 标题      | `# 一级` `## 二级` `### 三级`    |
| **粗体**  | `**文字**`                   |
| *斜体*    | `*文字*`                     |
| ~~删除线~~ | `~~文字~~`                   |
| 行内代码    | `` `代码` ``                 |
| 代码块     | 三个反引号包起来                   |
| 引用      | `> 引用内容`                   |
| 无序列表    | `- 项目`                     |
| 有序列表    | `1. 项目`                    |
| 任务列表    | `- [ ] 未完成` / `- [x] 已完成`  |
| 表格      | 用 `\|` 分列，第二行写 `\| --- \|` |
| 分隔线     | `---`                      |
| 链接      | `[文字](网址)`                 |
| 图片      | `![描述](图片地址)`              |
| 换行      | 行尾两个空格，或空一行的段落             |

### 表格怎么写

```markdown
| 列A | 列B |
| --- | --- |
| 内容1 | 内容2 |
```

渲染效果：

| 列A  | 列B  |
| --- | --- |
| 内容1 | 内容2 |

**注意**：第二行的 `---` 不能少，否则不认成表格。
  
但你不用手写——选中几行按 `Ctrl+T` 就行。

## 五、五个提效技巧

### 1. 选中多行秒变表格

写表格对齐符号很累。选中内容行：

```
产品名
价格
库存
```

按 `Ctrl+T`，得到：

```markdown
| 产品名 | 价格 | 库存 |
| --- | --- | --- |
|  |  |  |
```

光标停在空格里填内容即可。

### 2. 标题可以升降级

光标在标题行，按 `Ctrl+Alt+1` 变一级标题，
  
再按 `Ctrl+Alt+3` 变三级，**再按一次 `Ctrl+Alt+3`** 就变回正文。

### 3. 括号自动补全

输入 `(`、`*`、`_`、`` ` ``、`[`，轻墨会自动补上后半截，
  
光标停在中间，直接继续打就行。按 `End` 跳到末尾。

### 4. Tab 缩进

在列表里按 `Tab` 缩进一级变子项，`Shift+Tab` 提回来。

```
- 第一层
    - 第二层
```

### 5. 草稿不会丢

边打字边自动存本地。就算你直接杀进程强制关机，下次打开
  
文档还在（状态栏会显示「未保存」的橙色圆点）。

正式 `Ctrl+S` 保存成 `.md` 文件后，暂存清空。

## 六、常见问题

### Q：Windows 提示「未知发布者」怎么办？

轻墨没有购买微软的代码签名证书（一年几百美元，个人项目通常不做）。
  
点「更多信息」→「仍要运行」就行。

### Q：macOS 双击打不开，提示「已损坏」

因为没有 Apple 签名和公证，系统默认拦截。**右键点击 → 打开** 就好。

还不行的话，终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/QingMo.app
```

### Q：能打开 .md 文件吗？

能。用「文件 → 打开」选 `.md` 文件，或直接把文件拖进窗口。

### Q：导出 HTML 是干什么的？

生成一个独立的 `.html` 网页文件，双击就能在浏览器打开，
  
自带排版样式和深色模式适配。适合发给别人或放到网站。

### Q：支持哪些扩展名？

默认识别 `.md` `.markdown` `.mdown` `.mkd`。

### Q：文件会传到网上吗？

不会。轻墨完全离线运行，没有服务器、没有账号、不收集任何数据。

### Q：能装到手机吗？

不行，轻墨是桌面应用（Windows / macOS）。

### Q：怎么换字体？

编辑器字体在 `style.css` 的 `--mono` 变量，
  
预览字体在 `--font` 变量，改完重新打包即可。

## 七、文件放哪里

轻墨本身不管理文件，你保存到哪它就打开哪个。

Windows 常见的：

- 文档：`C:\Users\你的用户名\Documents\`
- 桌面：`C:\Users\你的用户名\Desktop\`

macOS 常见的：

- 文稿：`~/Documents`（访达 → 前往 → 个人，或按 `⌘+Shift+H` 看主目录）

### 建议的整理方式

```
Documents/
├── 工作/
│   ├── 周报/
│   │   ├── 2026-W42.md
│   │   └── 2026-W43.md
│   └── 项目/
│       └── 需求文档.md
└── 笔记/
    └── 读书笔记.md
```

轻墨的「最近打开」菜单会记录最近用过的 10 个文件，
  
找起来比翻文件夹快。
