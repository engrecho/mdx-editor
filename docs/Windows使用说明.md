# 轻墨 QingMo — Windows 版说明

本目录有 **3 种形态**，用途不同，别下错了。

---

## 三种文件对比

| 名称 | 大小 | 双击会怎样 | 用它做什么 |
| --- | --- | --- | --- |
| `轻墨 Setup 1.2.1.exe` | 83 MB | 弹出安装向导 | **日常使用推荐**，装到电脑里 |
| `轻墨 1.2.1.exe` | 83 MB | 先解压到临时目录，再启动，**首次会等 5-10 秒** | 只想临时用一次，或放 U 盘 |
| `portable/轻墨.exe` | 189 MB | **立即启动**，没有解压过程 | 真正的"双击即用" |

### 关键区别

**`轻墨 1.2.1.exe`（单文件版）不是真正的单文件程序。**

它是个 NSIS 自解压安装器，双击后会把 293MB 的完整应用解压到
`%TEMP%` 再启动。所以：

- 首次启动**明显慢**（5-10 秒），要等它解压
- 杀毒软件可能报警（自解压行为容易误判）
- 每次运行都要重新解压

**如果你想要「点了就开、秒启动」，用 `portable/` 目录里的那个。**

用法：把整个 `portable/` 文件夹复制到任意位置（U 盘也行），
双击里面的 `轻墨.exe`。整个文件夹是完整的，**不能只拷 exe**。

## 该选哪个

| 你的情况 | 选|
| --- | --- |
| 每天用，固定装在电脑上 | `轻墨 Setup 1.2.1.exe` |
| 临时打开一次某个 .md | `轻墨 1.2.1.exe` |
| 放 U 盘随身带，追求秒开 | `portable/` 整个文件夹 |
| 公司的电脑，不允许安装 | `portable/` 整个文件夹 |

## 安装版会被拦吗？

可能会。Windows提示「未知发布者」，因为没买代码签名证书（一年几百美元，个人项目一般不做）。

**解决办法**：

1. 点「更多信息」
2. 点「仍要运行」

或者：右键 → 属性 → 底部勾选「解除锁定」→ 确定，之后就能正常双击。

---

## 文件放哪？

程序装哪都行，但**你编辑的 .md 文件自己保管**，软件不负责备份。

建议：

- 用「文件 → 打开」选文档，或直接把 .md 拖进窗口
- 用「文件 → 另存为」保存到你自己的目录（如 `文档\笔记\`）
- 状态栏显示「已保存」（绿色）才是真的存到磁盘了
- 显示「● 未保存」（橙色圆点）说明改动只在编辑区里，**这时候关窗口虽然有草稿暂存，但不保险**

轻墨不联网、不上传、不收集任何数据，文件只在你本机。

---

## 卸载

安装版：Windows 设置 → 应用 → 找到「轻墨」→ 卸载。

便携版（单文件或 portable 目录）：直接删掉即可，不留注册表。
