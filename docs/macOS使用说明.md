# 轻墨 QingMo — macOS 版说明

本目录有 **2 个文件**，按你的 Mac 芯片选一个。

---

## 选哪个文件

| 你的 Mac                      | 文件                           | 大小     |
| --------------------------- | ---------------------------- | ------ |
| M1 / M2 / M3 / M4（Apple 芯片） | `QingMo-1.3.0-mac-arm64.zip` | 97 MB  |
| Intel 芯片（2019 年前的机型）        | `QingMo-1.3.0-mac-x64.zip`   | 101 MB |

**怎么知道自己是什么芯片**：左上角  → 关于本机 → 看「芯片」那一行。  
显示「Apple M1/M2/M3/M4」就用 arm64，显示「Intel」就用 x64。

2020 年后买的 Mac 基本都是 Apple 芯片。

---

## 安装步骤

1. 双击解压 zip，得到 `QingMo.app`
2. 把 `QingMo.app` 拖进「应用程序」文件夹
3. **首次打开：右键点击 `QingMo.app` → 选择「打开」**
4. 在弹出的对话框里，再点一次「打开」

完成。访达里显示的名字&#x662F;**「轻墨」**，右键打开后以后就能正常双击了。

---

## 为什么必须右键打开？

因为应用**没有 Apple 签名和公证**。

macOS 的 Gatekeeper 会对未签名应用直接拦截，双击只会弹「已损坏，无法打开」，  
这是误报——应用本身没问题。

绕过方式就是**右键 → 打开**，这是 Apple 官方留的口子。

### 右键也不行的话

打开「终端」（聚焦搜索 Terminal），粘贴执行：

```bash
xattr -dr com.apple.quarantine /Applications/QingMo.app
```

然后再双击。

---

## 能免掉这个提示吗？

能，但需要：

- Apple 付费开发者账号（$99/年）
- 在 Mac 上用 `codesign` 做代码签名
- 提交 Apple 公证（notarization）

个人项目一般不建议为一次性的发布付这个钱。如果要发布正式版本，  
在 Mac 上跑 `npm run pack:mac` 出 `.dmg`，再配签名即可。

---

## 这是 zip 不是 dmg

`.dmg` 需要 macOS 系统的 `hdiutil` 工具生成，**在 Windows 上做不出来**。

本目录的 `.app` 已经打包好了，Windows 上交叉生成，省得你装个虚拟机。  
解压出来和正常 `.app` 完全一样，只是少了 dmg 那个「拖到应用程序」的安装壳。

如果你以后有 Mac 机器，想出正式 dmg：

```bash
npm run pack:mac
```

## 常见问题

**Q：能打开 .md 文件吗？**  
能。「文件 → 打开」选 `.md`，或直接把文件拖到窗口上。

**Q：文件会上传吗？**  
不会。完全离线运行，无账号、无服务器、不收集任何数据。

**Q：怎么卸载？**  
把 `/Applications/QingMo.app` 拖到废纸篓即可。

**Q：怎么升级？**  
下载新版 `.app` 覆盖旧的，或者先删旧的再拖新的。

**Q：应用名和文件名不一致？**  
`QingMo.app` 是 macOS 的命名惯例（内部标识用英文），  
你在访达和应用菜单里看到的都是中文「轻墨」。
